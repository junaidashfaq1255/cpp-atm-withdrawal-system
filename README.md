# ATM Withdrawal System in C++

## Description
A simple ATM simulation program developed in C++ for a Programming Fundamentals lab task. The program verifies the user's PIN, accepts a withdrawal amount, validates the amount, checks the available balance, and displays the remaining balance after a successful withdrawal.

## Features
- PIN verification
- Withdrawal amount validation
- Insufficient balance detection
- Balance calculation after withdrawal
- Nested if-else statements

## Initial Balance
Rs. 50,000

## Language
C++

## Concepts Used
- Variables and data types
- `cin` and `cout`
- Nested `if-else` statements
- Conditional statements and arithmetic operations
